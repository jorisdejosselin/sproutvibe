# Changelog

## [1.0.0](https://github.com/jorisdejosselin/sproutvibe/releases/tag/v1.0.0) (2026-03-25)

### Initial public release

* FastAPI backend with SQLite / PostgreSQL support
* React + Vite PWA frontend with TailwindCSS
* Plant management with care schedules and journal entries
* AI care suggestions (Anthropic Claude API)
* Plant species search (Perenual / FloraCodex)
* Push notifications for care reminders
* Kiosk / demo mode with auto-provisioned demo users
* Docker Compose and Kubernetes (Helm) deployment
* Android APK via Capacitor
* MCP server for Claude Desktop integration
* Settings encryption at rest (Fernet)
